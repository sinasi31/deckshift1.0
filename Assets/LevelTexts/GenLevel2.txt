// GenLevel2 — "The Undercroft"
// Shape: enter HIGH on the left, exit LOW on the right. Falling is free,
// climbing costs Shift — the room is built around that asymmetry.
//
// MAIN ROUTE (cheap, ~2-3 Shift): descend the left shelf ladder for free
//   (shelf -> P1 -> P2 -> P3), cross the 5-wide spike moat (hop the hovering
//   stone, or long-jump it from P3 if you're brave), pass the tower, hop the
//   second spike strip, exit. Slimes and skeletons patrol the floor.
// THE TOWER: a hollow crypt tower mid-room. Its base hides the SECRET —
//   a breakable bookshelf sealing gold + a crystal inside.
// HIGH ROUTE (expensive, rewarded): moat stone -> hover stone -> tower roof,
//   then a 4-stone zigzag climb (AeroBat contests it) up to the GALLERY: a
//   long shelf under the ceiling holding gold, a Chest... and a Mimic sitting
//   right beside it. Pick carefully. Drop off the gallery's right end to land
//   at the exit.
// All climbs are exactly 3-tile rises (max jump ~4). Backwall: added by hand.
