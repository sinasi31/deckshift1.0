// GenLevel1 — "The Crossing"
// Design intent:
//   GROUND ROUTE (cheap): left to right, 2 spike pits + a forced plateau climb (~3 Shift).
//   HIGH ROUTE (expensive, rewarded): plateau -> A -> C -> stepping stones -> treasure
//     shelf with the Chest, guarded by an AeroBat. Crystals refund the spent Shift.
//   RIGHT WING (spicy): B -> D jump over the second spike pit, ranged enemy on D,
//     gold on B, crystal over F, drop-down lands you at the exit.
//   SECRET: breakable wall (W) at the base of the spawn ledge hides an alcove
//     with gold + a crystal. The Mimic near the exit punishes greed.
// All rises are exactly 3 tiles (max single jump is ~4).
